## 1. Что вписать в `.env`

Полный список ключей — в `.env.example`. Новое и изменённое для этапа 3:

| Переменная | Что вписать |
|---|---|
| `SITE_ORIGIN` | `https://<домен>` — без слэша в конце; по нему api проверяет `Origin` WebSocket |
| `DJANGO_ALLOWED_HOSTS`, `CSRF_TRUSTED_ORIGINS` | домен сайта (`CSRF_TRUSTED_ORIGINS` — с `https://`) |
| `DEBUG` | `False` |
| `API_DB_USER`, `API_DB_PASSWORD` | имя и новый пароль отдельной роли БД для api (без доступа к заказам, заявкам и пользователям). Роль создаётся сама при старте |
| `ANTHROPIC_API_KEY` | ключ Claude API |
| `ANTHROPIC_MODEL` | пусто (по умолчанию `claude-opus-5-5`) |
| `ANTHROPIC_PROXY_URL` **или** `ANTHROPIC_BASE_URL` | прокси — одна из двух: `http://логин:пароль@хост:порт` (прямой прокси) или `https://адрес/` (обратный прокси вместо api.anthropic.com) |
| `AGENT_EFFORT` | значение после подбора (см. «Запустить с ключом», шаг 5); пусто — `low` |
| `AGENT_PREFIX_MISMATCH` | пусто (`drop_block`) |
| `EMAIL_BACKEND` | `django.core.mail.backends.smtp.EmailBackend` |
| `EMAIL_HOST` / `EMAIL_PORT` | `smtp.yandex.ru` / `465` |
| `EMAIL_USE_SSL` / `EMAIL_USE_TLS` | `True` / `False` — одновременно включать нельзя |
| `EMAIL_HOST_USER` | полный адрес ящика |
| `EMAIL_HOST_PASSWORD` | пароль приложения Яндекса (не пароль аккаунта) |
| `DEFAULT_FROM_EMAIL` | тот же адрес, что `EMAIL_HOST_USER` — иначе Яндекс отклонит письмо |
| `MANAGER_EMAIL` | адрес администратора |
| `NOTIFY_EMAILS` | адреса рассылки через запятую (письма со счётом, о смене статуса, о заявках) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | как сейчас |
| `TELEGRAM_ADMIN_LINKS` | пусто (`True`) — в Telegram приходит ссылка в админку; `False` — без ссылки |
| `CHAT_WIDGET_ENABLED` | **`False`** на время приёмки; `True` — после неё (шаг 6) |
| `CHAT_DAILY_BUDGET_USD` | пусто ($20 в сутки) или своё значение; `0` — без ограничения |
| `CHAT_MESSAGES_PER_*`, `CHAT_MAX_MESSAGE_LENGTH` | пусто — 6 в минуту, 50 в сутки на посетителя, 60 в диалоге, 2000 символов |
| `PAYMENT_LINK_ENABLED` | пусто (`False`) — оплата пока заглушка |

## 2. HTTPS

Сейчас Caddy слушает `:80` без сертификата (`auto_https off`). На сервере без HTTPS не работает вход (защищённые cookies при `DEBUG=False`) и `wss://` для чата. Если HTTPS ещё не настроен:
- в `Caddyfile` заменить `:80` на домен и убрать блок `auto_https off` — Caddy сам получит сертификат;
- в `docker-compose.yml` у `caddy` открыть порт `443:443`.

## 3. Запуск

```
git pull
docker compose up -d --build        # без docker-compose.dev.yml — он для разработки
docker compose ps                    # postgres, redis, catalog, api — healthy; caddy — Up
```

При старте `catalog` сам: применяет миграции, выдаёт права роли api, загружает базу знаний (если её нет), загружает курсы ЦБ.

## 4. Проверки после запуска

| Что | Команда | Ожидается |
|---|---|---|
| Сайт | `curl -sI https://<домен>/` | `200` |
| Подключение к Claude API через прокси | `docker compose run --rm api python scripts/check_proxy.py` | все пункты OK (несколько центов) |
| Почта | `docker compose exec -T catalog python manage.py sendtestemail <адрес>` | письмо пришло |
| Счета и КП не раздаются напрямую (T17) | `curl -s -o /dev/null -w "%{http_code}" https://<домен>/media/invoices/x.pdf` | `404` |
| Маскирование на каталоге (T18) | `docker compose exec -T api python scripts/check_masking.py` | `OK` |
| В образах нет `.env` (T19) | `scripts/check_images.sh` | `OK` для обоих |
| База знаний | админка → «База знаний» | есть активная версия; через ~5 минут появится размер в токенах |
| Курсы ЦБ | админка → «Курсы ЦБ» | курсы на сегодня |

## 5. Приёмка с ключом (чат ещё выключен)

```
docker compose exec -T catalog python manage.py acceptance > backups/acceptance-$(date +%F).md
```
~15 минут и ~$10. В отчёте — итог по каждому диалогу 1–14, стоимость и T2. Пункты 👀 смотрит человек по переписке в отчёте. Письма и Telegram во время приёмки наружу не уходят.

После просмотра отчёта:
```
docker compose exec -T catalog python manage.py acceptance --cleanup
```

## 6. Включить чат

```
# в .env: CHAT_WIDGET_ENABLED=True
docker compose up -d catalog
```
Открыть главную в браузере: строка «ИИ подберёт для вас оборудование» → вопрос → окно чата → карточки. Откат — `CHAT_WIDGET_ENABLED=False` и `docker compose up -d catalog`: сайт работает как раньше, без чата.

## 7. Cron на хосте

`crontab -e` (путь к проекту — свой):
```
# Курсы ЦБ: днём ЦБ публикует курс на завтра, ночью — на случай сбоя дневной загрузки
30 15 * * * cd /opt/ai-dent && docker compose exec -T catalog python manage.py update_currency_rates >> /var/log/ai-dent-cron.log 2>&1
5 0 * * *   cd /opt/ai-dent && docker compose exec -T catalog python manage.py update_currency_rates >> /var/log/ai-dent-cron.log 2>&1
# Гостевые сессии старше 90 дней (диалоги с заказом или заявкой не трогаются)
30 3 * * *  cd /opt/ai-dent && docker compose exec -T catalog python manage.py cleanup_anon_sessions >> /var/log/ai-dent-cron.log 2>&1
```
Если курс валюты не обновлялся 7 дней, команда курсов пишет предупреждение в Telegram.

## 8. Первые дни

- Админка → «Расход модели»: сводка по дням — стоимость, на диалог, доля чтения из кэша (должна быть высокой), доля резервной модели.
- При исчерпании суточного бюджета чат переходит в режим «только заявка» до полуночи по Москве; главная показывает «Агент временно не работает» и поиск по каталогу.
- Через неделю — уточнить `CHAT_DAILY_BUDGET_USD` и лимиты по фактическому расходу.
- Логи агента: `docker compose logs -f api` (без текстов сообщений — только идентификаторы и счётчики).

# Запустить с ключом

То, что требует платной модели. Локально — с ключом в `.env` и VPN, на сервере — через прокси. Стенд — без `docker-compose.dev.yml`.

1. **Подключение**
   ```
   docker compose up -d --build
   docker compose run --rm api python scripts/check_proxy.py
   ```
2. **Размер базы знаний в токенах** — считается сам в фоне api после старта с ключом; через ~5 минут проверить в админке «База знаний».
3. **Приёмочные диалоги 1–14 и T2 (кэш)**
   ```
   docker compose exec -T catalog python manage.py acceptance > acceptance.md
   ```
4. **T13 — строгая проверка истории** (`prefix_mismatch_behavior: error`) на диалогах с инструментами и сменой базы знаний:
   ```
   AGENT_PREFIX_MISMATCH=error docker compose up -d api
   docker compose exec -T catalog python manage.py acceptance --only 1,8,12 > t13.md
   docker compose up -d api            # вернуть drop_block
   ```
   Пройдено, если в диалогах нет ошибок модели.
5. **Подбор `effort`** — сравнить качество и цену:
   ```
   AGENT_EFFORT=medium docker compose up -d api
   docker compose exec -T catalog python manage.py acceptance --only 1,2,4,6 > effort-medium.md
   docker compose up -d api            # обратно к значению из .env
   ```
   Сравнить с теми же диалогами в `acceptance.md` (`low`): ответы и столбец «Стоимость». Выбранное значение вписать в `AGENT_EFFORT`.
6. **Модель (Q2, по желанию)** — то же для `claude-sonnet-5-5` (вдвое дешевле за токен):
   ```
   ANTHROPIC_MODEL=claude-sonnet-5-5 docker compose up -d api
   docker compose exec -T catalog python manage.py acceptance --only 1,2,4,6 > sonnet.md
   docker compose up -d api
   ```
7. **Уборка** после всех прогонов:
   ```
   docker compose exec -T catalog python manage.py acceptance --cleanup
   ```
