## Что проверил

- **Автотесты** — все проходят: Django 271, api 292, фронтенд 13.
- **Приёмка на подменной модели**, 10 диалогов без базы знаний. Работают: корзина, КП, заказ, заявка, цены только из каталога, рубли по курсу ЦБ, маскировка телефона, «продай за 1 ₽» не проходит. Не прошёл диалог 1 — там нужно понимание вопроса, подменная модель его не даёт.
- **Исправил приёмку**: сценарий отправлял заказ лупы без параметров и падал. Теперь он отмечает «параметры уточнит менеджер», как клиент.

- **Не проверял качество текста** ответов: для этого нужна живая модель.

## Работает хорошо

- Цены только из каталога, скидок не даёт, на «забудь правила» не ведётся.
- Личные данные — только через формы, в чате маскируются.
- Корзина, КП, заказ и счёт работают прямо из чата.
- Сбои и лимиты: понятный текст и кнопка «Оставить заявку».

## Что улучшить — по важности для клиента

1. **Лупа: параметры выбираются дважды.** Блок лупы (увеличение, расстояние) ничего не сохраняет. После него форма заказа спрашивает то же самое плюс оправу.
   → Кнопка «В корзину с этими параметрами» в блоке, форма заказа берёт выбор оттуда. Другой вариант — выбор только в форме, а блок оставить для просмотра поля обзора.
2. **Дубли на экране.** При подборе 2–3 моделей сначала идут карточки, потом таблица с теми же фото и ценами. На телефоне это 2 экрана прокрутки до ответа.
   → Для 2–3 моделей показывать только таблицу и добавить в неё кнопку «В корзину». Карточки — для 1 или 4 товаров.
3. **Ответ короче и по одной схеме:** рекомендация одной фразой → почему (2–3 пункта) → один следующий шаг. Сейчас инструкция себе противоречит: «пиши коротко», а для луп — «текст развёрнутый».
   → Убрать «развёрнутый», ограничить ответ примерно 5 строками на телефоне. Задавать один вопрос за раз, сейчас разрешено «один–два».
4. **Следующий шаг кнопками.** Под ответом 2–3 быстрых варианта: «Положить в корзину», «Сравнить с SLT», «Оформить». Клиенту не нужно печатать.
5. **Убрать пометку «Для терапевта» (pick) из инструкции и инструмента.** На экран она больше не выводится. ИИ тратит на неё силы и может сослаться на неё в тексте («отметил в таблице»).
6. **Мелочи.** При «Не получилось довести ответ до конца» показывать кнопку «Оставить заявку», а при «Диалог получился длинным» — «Новый диалог». Сейчас там только текст.
